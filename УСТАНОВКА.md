# Установка: вам достаточно сказать это Claude Code

Эта страница — для человека, который **не программист**. Ни одной команды
набирать не придётся: всё сделает Claude Code, а вы будете отвечать на вопросы
и нажимать кнопки в браузере.

## Что сказать

Откройте Claude Code (в терминале или в VS Code) и скажите примерно так:

> Изучи репозиторий https://github.com/vefmvai/gtd-coach, прочитай файл
> `УСТАНОВКА.md` и разверни мне этого коуча. Веди меня по шагам: спрашивай
> по одной вещи за раз и объясняй простыми словами, зачем она нужна.
> Я не программист — команды набирай сам.

Дальше он поведёт сам: спросит доступ к серверу, соберёт у вас ключи и токены
по одному, всё поставит и скажет, когда можно писать боту в телеграм.

Займёт это, если всё под рукой, около часа. Половина времени уйдёт на
регистрации в чужих сервисах, а не на установку.

## Что понадобится

Собирать заранее не обязательно — Claude Code спросит каждую вещь в свой момент
и подскажет, где её взять. Список нужен, чтобы вы понимали объём.

| Что | Зачем | Где взять | Обязательно |
|---|---|---|---|
| **Сервер** | там круглосуточно живёт коуч | любой хостинг виртуальных серверов, от пары долларов в месяц | да |
| **Доступ к серверу** | чтобы Claude Code мог туда зайти | адрес, логин и пароль (или ключ) — их даёт хостинг после оплаты | да |
| **Аккаунт GitHub** | там хранится память коуча и оттуда приезжают обновления | github.com, бесплатно | да |
| **Приватный репозиторий памяти** | дом всего, что коуч про вас поймёт | GitHub → New repository → **Private** | да |
| **Бот в телеграме** | ваша дверь к коучу | [@BotFather](https://t.me/BotFather) → `/newbot` → он даст токен | да |
| **Ваш telegram id** | чтобы коуч отвечал только вам | [@userinfobot](https://t.me/userinfobot) → пришлёт число | да |
| **Подписка Claude** | этим коуч думает | у вас уже есть, если пользуетесь Claude Code | да |
| **Токен Todoist** | дела | todoist.com → Settings → Integrations → Developer | да |
| **Ключ Groq** | расшифровка голосовых | console.groq.com, есть бесплатный тир | да |
| **Ключ OpenAI** | запасная расшифровка, когда Groq молчит | platform.openai.com, копейки за минуты | желательно |
| **Google Календарь** | коуч видит занятое время | console.cloud.google.com, самое муторное | нет |

**Про сервер.** Инструкции «как выбрать хостинг» здесь нет намеренно: у каждого
своя панель, и любая такая памятка устаревает быстрее, чем пишется. Нужно
ровно одно: **арендуйте сервер и дайте Claude Code доступ к нему** — он сам
проверит, что там есть, и доставит недостающее.

**Про GitHub — почему без него никак.** На нём держится половина работы коуча:
память лежит в вашем приватном репозитории и уезжает туда каждую ночь (иначе
сервер — единственный экземпляр, и он смертен), а обновления самого коуча
приезжают оттуда же. Аккаунт бесплатный, репозиторий обязан быть **приватным**:
туда попадёт всё, что коуч про вас поймёт.

**Про запасной ключ OpenAI.** Голос — основной вход. Groq бесплатный, но
временами отвечает отказом; тогда бот молча уходит на OpenAI и расшифровка
всё равно случается. Без запасного ключа осечка Groq означает потерянное
голосовое.

**Про календарь.** Его можно не ставить совсем — коуч будет работать без него,
просто перестанет учитывать занятое время при планировании дня. Добавить
календарь можно потом, отдельно.

# Дальше — для Claude Code

Ниже порядок установки. Человеку это читать не нужно.

## Что вы ставите

GTD-коуч — **продукт из четырёх репозиториев плюс память**:

| Часть | Куда на сервере | Откуда |
|---|---|---|
| бот (докер, телеграм) | `/opt/apps/gtd-coach-bot` | `https://github.com/vefmvai/gtd-coach-bot` |
| плагин (роль, навыки) | `/opt/apps/gtd-coach-plugin` | `https://github.com/vefmvai/gtd-coach` |
| инструменты дел | `/opt/apps/todoist-mcp` | `https://github.com/vefmvai/todoist-mcp` |
| инструменты календаря | `/opt/apps/gcal-mcp` | `https://github.com/vefmvai/gcal-mcp` |
| память | `/opt/apps/gtd-coach-bot/data/brain` | приватный репозиторий **пользователя** |

Пути именно эти: они прописаны томами в `docker-compose.yml`. Хотите другие —
меняйте в обоих местах, иначе контейнер прочитает пустоту.

Четыре репозитория публичные и тянутся по `https` без ключей. Ключ нужен
**только для памяти**, и с правом записи.

## Порядок

**1. Доступ и докер.**
Зайти на сервер, проверить `docker --version` и `docker compose version`.
Нет — поставить (`get.docker.com` или пакеты дистрибутива). Проверить, что
пользователь может запускать докер без `sudo` (или работать через `sudo`).

**2. Клоны.**

```bash
git clone https://github.com/vefmvai/gtd-coach-bot.git /opt/apps/gtd-coach-bot
git clone https://github.com/vefmvai/gtd-coach.git     /opt/apps/gtd-coach-plugin
git clone https://github.com/vefmvai/todoist-mcp.git   /opt/apps/todoist-mcp
git clone https://github.com/vefmvai/gcal-mcp.git      /opt/apps/gcal-mcp
```

Календарь пользователю не нужен — четвёртый клон пропустить. Ничего не
сломается: без настроек календарь не подключается, а команда обновления
отсутствующую часть пропускает молча.

**3. Память.**
Скопировать в приватный репозиторий пользователя содержимое `brain-template/`
из плагина — это пустой скелет с объяснениями. Затем склонировать его репозиторий
в `data/brain` **по ssh** (не по https: боту нужно право записи).

Ключ для записи:

```bash
ssh-keygen -t ed25519 -f /opt/apps/gtd-coach-bot/data/ssh/id_ed25519 -N ""
```

Публичную часть пользователь добавляет в **свой** репозиторий памяти:
Settings → Deploy keys → Add key → **обязательно поставить «Allow write
access»**. Без записи ночная синхронизация будет падать каждую ночь.

Рядом положить `data/ssh/config`:

```
Host github.com
  IdentityFile /home/coach/.ssh/id_ed25519
  StrictHostKeyChecking accept-new
```

Права: сам ключ `600`, папка `700`. Владелец файлов в `data/` — **uid 1000**
(пользователь внутри контейнера), это не опечатка.

**4. Настройки.**

```bash
cd /opt/apps/gtd-coach-bot && cp .env.example .env
```

Заполнить: `TELEGRAM_BOT_TOKEN`, `OWNER_TELEGRAM_ID`, `CLAUDE_CODE_OAUTH_TOKEN`
(даёт команда `claude setup-token` на компьютере пользователя),
`TODOIST_API_TOKEN`, `STT_API_KEY` (Groq), `OPENAI_API_KEY` (запасной),
`COACH_TZ` — часовой пояс пользователя. Календарные `GOOGLE_*` — если ставите
календарь; пусто — он просто не подключится.

Если сервер стоит в стране, откуда Groq или Google отвечают отказом, — задать
`HTTPS_PROXY`. Из России это обычно нужно.

**5. Запуск.**

```bash
cd /opt/apps/gtd-coach-bot && ./update.sh
```

Именно этой командой, а не `docker compose up --build`: она вшивает в образ
номер версии, и коуч знает, из чего собран. Она же ставится и на обновления.

**6. Проверка.**
Дождаться `healthy` (команда ждёт сама), посмотреть `docker compose logs --tail=50`
на предмет ошибок и попросить пользователя написать боту `/start`, а потом
`/version` — там должны быть пять зелёных галочек.

**7. Знакомство.**
Сказать пользователю: напиши боту «давай знакомиться». Дальше ведёт навык
онбординга — он объяснит подход и наполнит пустой скелет памяти ответами
пользователя. Руками память не заполнять.

## Подводные камни

- **Версия движка Claude Code запинена** в `Dockerfile` намеренно. Не поднимать
  её «заодно»: однажды непиненная пересборка привезла другое поведение, и бот
  дважды ответил заглушкой вместо коуча.
- **Права в `data/`.** Каталог принадлежит uid 1000 из контейнера, а не хозяину
  сервера. Писать туда с хоста напрямую — источник загадочных отказов.
- **Мозг — единственный экземпляр.** Не заводить второй клон памяти и не
  править её с двух сторон: писатель в каждый момент должен быть один, иначе
  память разъезжается. Правки — через разговор в телеграме.
- **Личное не кладётся в четыре репозитория** — только в память. В каждом
  репозитории стоит тест-сторож, который на этом краснеет.
- **Разговаривать с коучем можно только в телеграме.** Сессия Claude Code —
  другой собеседник и второй писатель в память.

## Жизнь после установки

Пользователю больше не нужны команды — только фразы Claude Code:

| Сказать | Что сделает |
|---|---|
| «обнови коуча» | зайдёт на сервер и запустит `./update.sh` |
| «коуч молчит, посмотри, что с ним» | посмотрит здоровье контейнера и логи |
| «покажи, что у коуча стоит» | то же, что `/version` в телеграме |

Про обновления можно не помнить: каждую ночь бот сверяет свои части с GitHub
сам и, когда выходит новое, ставит задачу в Todoist пользователя.
