# Стандарт памяти — кэш, а не дом

Файлы в этой папке — **реплика стандарта Loreground, версия 0.15.1**.
Дом текста — [vefmvai/loreground](https://github.com/vefmvai/loreground), лицензия MIT.

**Здесь ничего не правится.** Нужна правка стандарта — она делается в источнике,
сюда приезжает обновлением версии целиком. Правка на месте создаст второй дом
у факта, ровно то, против чего написан сам стандарт (§ 6 «Обновление фактов»).

## Зачем копия, если есть источник

Коуч живёт в контейнере на сервере, а Loreground как плагин туда не приезжает:

| Где | Loreground как плагин | Этот кэш |
|---|---|---|
| Компьютер, где правят плагин | ставится отдельно | не нужен, но безвреден |
| Контейнер бота на сервере | **нет** | единственный способ дотянуться |

Плагин `gtd-coach` смонтирован боту только на чтение — значит и стандарт для него
доступен только на чтение. Режим «указатель» здесь не работает: адрес
`~/.claude/plugins/...` внутри контейнера ведёт в пустоту.

Стандарт предусматривает этот случай режимом **«реплика»**: несколько мест, один
пишущий дом, клоны объявляются кэшем. Эта страница и есть такое объявление.

## Как обновлять

Поднять версию Loreground у себя, скопировать папку `standard/` заново
целиком, поднять номер версии в первой строке этого файла. Выборочная правка
одного файла — тот самый второй дом.
