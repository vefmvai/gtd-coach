# Профиль в замерах: ряд по неделям

> Модуль **журнал**: только дописывается. **Файл ведёт код**, а не человек.

Раз в неделю ночной прогон дописывает сюда строку показателей — тех же, что
лежат в `состояние/профиль-показатели.md`. Там всегда «как сейчас», здесь —
«как менялось».

Ряд нужен для разговоров, где важна динамика, а не срез: «твоя медиана срока
жизни задачи выросла с полутора дней до четырёх — что изменилось в августе?».

Файл пуст, пока не прожита первая неделя.
